# Instrument docs so improvements are measurable

> Search analytics, feedback widgets, and journey tracking driving docs roadmaps with evidence.

**Track:** ✍️ Technical Writing · **Domain:** Docs Operations · **Level:** intermediate · **~30 min**

**Who this is for:** Technical Writers, Developer Advocates, Engineers Who Document, Content Leads

## When to Use This Skill

Search analytics, feedback widgets, and journey tracking driving docs roadmaps with evidence.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Log site search queries with zero-results as content backlog
2. Per-page 👍/👎 with optional reason; route negatives to owners weekly
3. Track page-to-next-action conversion (did reader succeed?)
4. Correlate support tickets with missing/failed doc journeys monthly
5. Report docs health quarterly: freshness %, satisfaction trend, deflection value
6. Never A/B content changes without enough traffic to matter

## Common Pitfalls

- Vanity pageviews rewarding SEO bait over task success
- Feedback widget collecting dust with no triage owner
