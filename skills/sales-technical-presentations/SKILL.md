# Deliver winning technical presentations

> Technical presentations to engineering and IT evaluators that land architecture, proof of value, and Q&A credibility. Use when a deal needs a technical pitch, an architecture review, or a formal technical evaluation.

**Track:** 🤝 Sales & Customer Success · **Domain:** Discovery & Deals · **Level:** advanced · **~40 min**

**Who this is for:** Account Executives, Customer Success Managers, Sales Engineers, Founders Selling

## When to Use This Skill

Technical presentations to engineering and IT evaluators that land architecture, proof of value, and Q&A credibility. Use when a deal needs a technical pitch, an architecture review, or a formal technical evaluation.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Ask what the technical audience must believe to say yes, then build the deck backwards from that list instead of from the feature map
2. Open with their current architecture and the constraint it imposes, then show only the delta; engineers reject solutions that ignore what they already run
3. Put the hardest technical objection on a slide with the answer attached, so it is never a surprise in the room
4. Carry one proof artifact per claim: a benchmark with its environment named, a reference customer at comparable scale, a security answer with the document behind it
5. Rehearse the Q&A out loud with someone who interrupts on purpose; the objection that lands in the room is the one you have not answered yet
6. Close with a named next step, an owner, and a date, because a technical evaluation without a scheduled follow-up decays into silence

## Common Pitfalls

- Replaying a sales deck to a security review whose real agenda is data handling and lock-in
- Claiming performance numbers with no environment, no workload, and no way for the evaluator to reproduce them

## Success Signals

- Technical evaluation advances within five working days of the presentation
- Every slide claim traceable to a proof artifact
- Zero unanswered technical questions left in the follow-up thread
