# Playbook: Polish interactions users feel

> Rage-free forms, honest optimistic UI, and infinite scroll that respects users.

**Track:** 🗺️ Frontend Engineering · **Domain:** Journey Playbooks · **Level:** journey · **~90 min**

**Who this is for:** Frontend Engineers, Full-Stack Developers, Design Engineers, UI Developers

## When to Use This Skill

Rage-free forms, honest optimistic UI, and infinite scroll that respects users.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Journey Steps

1. Step 1 — Build forms people complete without rage: start with "One column, visible labels above fields, optional marked never hidden"
2. Step 2 — Apply optimistic UI where it pays: start with "Reserve optimism for actions easily undone or near-certain to succeed"
3. Step 3 — Ship infinite scroll without trapping users: start with "Trigger next page well before bottom (rootMargin 600px+)"
4. How it fits together: Every pattern here has an anti-pattern twin; the pitfalls sections are the product.
