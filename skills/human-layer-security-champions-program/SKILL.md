# Launch a security champions program

> Embedded team advocates with training, authority, and recognition multiplying security capacity.

**Track:** 🔐 Cybersecurity · **Domain:** Human Layer · **Level:** intermediate · **~35 min**

**Who this is for:** Security Engineers, AppSec, DevSecOps, Compliance Teams

## When to Use This Skill

Embedded team advocates with training, authority, and recognition multiplying security capacity.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Recruit one volunteer per product team; never assign unwilling conscripts
2. Give real training budget plus direct channel to security team
3. Delegate concrete authority: approve low-risk exceptions, veto dangerous deps
4. Meet biweekly as a guild; rotate case studies between teams
5. Recognize contributions in performance cycles formally
6. Measure coverage by teams-covered and issues-caught-left-shift

## Common Pitfalls

- Champions becoming uncredited extra workload, burning them out
- Program dying when founding champion changes teams
