# Monitor training load without gadget worship

> Simple consistent measures — sRPE, duration, wellness — trended per athlete over time.

**Track:** 🏆 Sports & Performance · **Domain:** Training Design · **Level:** foundation · **~25 min**

**Who this is for:** Coaches, S&C Specialists, Athletic Trainers, Team Scientists

## When to Use This Skill

Simple consistent measures — sRPE, duration, wellness — trended per athlete over time.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Collect session RPE × minutes within 30min post-session, consistently
2. Compute acute (7d) vs chronic (28d) ratio; flag spikes above agreed band
3. Add one subjective wellness signal daily (sleep/soreness/mood scale)
4. Trend INDIVIDUALLY; population averages hide the athlete at risk
5. Act on flags via conversation first, dashboards second
6. Review monitoring usefulness each season; delete vanity metrics

## Common Pitfalls

- ACWR treated as physics instead of a rough flag
- Data collected but never changing tomorrow's session
