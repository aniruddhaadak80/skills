# Run FinOps before finance finds the invoice

> Tagging discipline, unit-economics dashboards, and anomaly alerts keeping cloud spend explainable.

**Track:** ☁️ DevOps & Cloud · **Domain:** Engineering Economics · **Level:** intermediate · **~35 min**

**Who this is for:** DevOps Engineers, SREs, Cloud Architects, Platform Engineers

## When to Use This Skill

Tagging discipline, unit-economics dashboards, and anomaly alerts keeping cloud spend explainable.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Enforce tag schema at provisioning time; untagged resources quarantined
2. Report cost per product/feature/unit — totals alone change nothing
3. Alert on absolute AND percentage anomalies within 24h detection window
4. Right-size reviews quarterly using utilization data, not vendor recommendations blindly
5. Credit commitments purchased after 60 days of stable baseline usage
6. Publish savings leaderboard internally; celebrate engineers who delete things

## Common Pitfalls

- Reserved purchases locking three-year regret
- Cost visibility arriving monthly when damage is already done
