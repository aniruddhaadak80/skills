# Install secure-SDLC gates developers respect

> Shift-left automation, threat-model triggers, and exception governance embedded in normal flow.

**Track:** 🔐 Cybersecurity · **Domain:** Security Program · **Level:** advanced · **~40 min**

**Who this is for:** Security Engineers, AppSec, DevSecOps, Compliance Teams

## When to Use This Skill

Shift-left automation, threat-model triggers, and exception governance embedded in normal flow.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Gate merges on SAST/secret-scanning/dependency-criticals with tuned rulesets
2. Trigger lightweight threat models by change-type (new authn, payments, file handling)
3. Make secure defaults the easy path: templates, paved-road libraries
4. Exceptions time-boxed with owner + compensating control, centrally visible
5. Measure gate noise monthly; tune detectors instead of training workarounds
6. Champions program: embed security-skilled engineers inside product teams

## Common Pitfalls

- Gates so noisy devs route around them within a sprint
- Threat models performed only when auditors ask
