# Write support replies that de-escalate

> Acknowledge → diagnose → act → verify structure with tone that survives angry Mondays.

**Track:** 💬 Customer Support · **Domain:** Ticket Excellence · **Level:** foundation · **~25 min**

**Who this is for:** Support Engineers, CX Leads, Helpdesk Teams, Technical Account Managers

## When to Use This Skill

Acknowledge → diagnose → act → verify structure with tone that survives angry Mondays.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. First sentence reflects THEIR stake ('your checkout being down is serious')
2. Never blame user or system in the same breath as apologizing
3. State what you DID, not just what they should try
4. Give one clear next step, not five options ending in question marks
5. Close with verification path if the fix doesn't hold
6. Re-read as the customer before sending; delete internal jargon

## Common Pitfalls

- Template walls where sentence two ignores sentence one's problem
- 'Per our policy' as an opening move
