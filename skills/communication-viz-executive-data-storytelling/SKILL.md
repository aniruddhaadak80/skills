# Tell data stories executives act on

> Headline-first structure, one-chart-one-message discipline, and pre-wired decisions.

**Track:** 📊 Data Science & Analytics · **Domain:** Communication & Visualization · **Level:** intermediate · **~30 min**

**Who this is for:** Data Scientists, Analysts, Research Scientists, Product Analysts

## When to Use This Skill

Headline-first structure, one-chart-one-message discipline, and pre-wired decisions.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Open with the decision needed, not methodology ancestry
2. One chart = one message; headline states the takeaway sentence
3. Pre-wire key stakeholders before any meeting; no ambush reveals
4. Quantify recommendation impact ranges with assumptions listed
5. Anticipate the three hardest questions; have backup slides ready
6. End with owner + date on next step, minuted

## Common Pitfalls

- Chart dumps requiring audiences to do analyst work
- Buried lede: conclusion arriving at slide 14
