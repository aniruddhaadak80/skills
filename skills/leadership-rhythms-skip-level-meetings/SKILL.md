# Run skip-levels that surface truth

> Psychologically safe formats hearing unfiltered reality two layers down without undermining managers.

**Track:** 🧭 Engineering Leadership · **Domain:** Leadership Rhythms · **Level:** intermediate · **~25 min**

**Who this is for:** Engineering Managers, Tech Leads, Staff Engineers, CTOs

## When to Use This Skill

Psychologically safe formats hearing unfiltered reality two layers down without undermining managers.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Explain purpose to BOTH manager and report beforehand — no secret meetings
2. Ask forward-looking questions: what should change, what's confusing
3. Never action individual complaints without consent to attribute
4. Batch systemic themes back to managers as patterns, not accusations
5. Cover everyone across two quarters, not just the vocal volunteers
6. Track whether surfaced issues actually die or get fixed

## Common Pitfalls

- Skip-levels as manager-performance stings discovered later
- Insight collection without any visible follow-through
