# Create a style guide writers actually follow

> Decision-recorded standards, linted enforcement, and exception paths keeping voice consistent at scale.

**Track:** ✍️ Technical Writing · **Domain:** Standards & Governance · **Level:** intermediate · **~35 min**

**Who this is for:** Technical Writers, Developer Advocates, Engineers Who Document, Content Leads

## When to Use This Skill

Decision-recorded standards, linted enforcement, and exception paths keeping voice consistent at scale.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Codify existing best decisions rather than inventing ideals nobody meets
2. Automate enforceable rules in linters; document only what tools can't catch
3. Cover the top confusion areas: terminology, capitalization, numbers, tone
4. Provide quick-reference card alongside full guide
5. Route disputes through documented amendment process, not arguments
6. Review annually against actual writer friction points observed

## Common Pitfalls

- 500-line guides consulted by no one ever
- Rules contradicting each other across chapters
