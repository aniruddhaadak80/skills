# Progress return-to-play by criteria, not calendars

> Stage gates with objective tests protecting athletes from rush-back reinjury.

**Track:** 🏆 Sports & Performance · **Domain:** Training Design · **Level:** advanced · **~40 min**

**Who this is for:** Coaches, S&C Specialists, Athletic Trainers, Team Scientists

## When to Use This Skill

Stage gates with objective tests protecting athletes from rush-back reinjury.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Define stage criteria BEFORE injury happens where possible
2. Each stage: pain-free capacity → sport-specific loads → reactive chaos
3. Test objectively per stage (strength symmetry, hop tests, speed percentages)
4. Progress on criteria met, never on schedule pressure alone
5. Include psychological readiness — fear of reinjury predicts actual risk
6. Full clearance requires full training week completed symptom-free

## Common Pitfalls

- Calendar-based clearances driven by fixture pressure
- Skipping the final 'chaos' stage straight into competition
