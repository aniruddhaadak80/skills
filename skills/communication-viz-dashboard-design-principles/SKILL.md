# Design dashboards people check daily

> Audience-first layout, five-second answers, and maintenance ownership preventing dashboard rot.

**Track:** 📊 Data Science & Analytics · **Domain:** Communication & Visualization · **Level:** foundation · **~25 min**

**Who this is for:** Data Scientists, Analysts, Research Scientists, Product Analysts

## When to Use This Skill

Audience-first layout, five-second answers, and maintenance ownership preventing dashboard rot.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Name the audience and their one recurring question before opening tools
2. Top-left = most important number with comparison (vs last week/target)
3. Color meaning consistent: red=bad everywhere, never decorative
4. Every tile links to investigation path (drill-down or query)
5. Assign an owner responsible for accuracy and retirement
6. Delete tiles unused for 90 days — dashboards are gardens

## Common Pitfalls

- Kitchen-sink grids serving nobody's actual decision
- Broken tiles persisting for months signalling abandonment
