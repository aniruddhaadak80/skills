# Run telehealth visits that clinically satisfy

> Pre-visit tech checks, structured remote exams, documentation parity, and escalation ladders.

**Track:** 🏥 Healthcare & Clinical · **Domain:** Telehealth Operations · **Level:** intermediate · **~30 min**

**Who this is for:** Nurses, Physicians, Clinical Managers, Health Informaticists

## When to Use This Skill

Pre-visit tech checks, structured remote exams, documentation parity, and escalation ladders.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Tech-check patients before visit day; failures reschedule gracefully
2. Open with identity/location verification per licensure requirements
3. Structure guided self-exam maneuvers with camera positioning coaching
4. Document modality limitations explicitly in the clinical record
5. Define in-person conversion triggers before starting the visit
6. Close with written visit summary sent through secure channel

## Common Pitfalls

- Platform failures consuming half the appointment slot
- Remote exams documented as complete physicals dishonestly
