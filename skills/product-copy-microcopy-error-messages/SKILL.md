# Write microcopy that helps instead of blames

> Error messages, empty states, and button labels engineered for user recovery.

**Track:** ✍️ Technical Writing · **Domain:** Product Copy · **Level:** foundation · **~20 min**

**Who this is for:** Technical Writers, Developer Advocates, Engineers Who Document, Content Leads

## When to Use This Skill

Error messages, empty states, and button labels engineered for user recovery.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Error formula: what happened + why + what to do now — no blame words
2. Buttons state outcomes ('Save draft') not vague verbs ('OK')
3. Empty states teach: what will live here + how to fill it
4. Never expose internal codes alone; translate for humans
5. Keep strings short enough for translation expansion (+30%)
6. Test copy with five users confused by something else entirely

## Common Pitfalls

- 'Something went wrong' as complete error communication
- Cute jokes at users' most frustrated moment
