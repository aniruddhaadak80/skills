# Receive design handoffs without rework loops

> Pre-build alignment on states, breakpoints, and motion specs eliminating mid-sprint surprises.

**Track:** 🎨 Frontend Engineering · **Domain:** Collaboration Flows · **Level:** intermediate · **~25 min**

**Who this is for:** Frontend Engineers, Full-Stack Developers, Design Engineers, UI Developers

## When to Use This Skill

Pre-build alignment on states, breakpoints, and motion specs eliminating mid-sprint surprises.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Walk designs asking: empty/loading/error/partial states for EACH screen
2. Confirm breakpoint behaviors explicitly; assume nothing scales gracefully
3. Agree interaction specs: durations, easing, what animates vs snaps
4. Flag technically-risky elements BEFORE estimation, not during build
5. Get accessibility intent stated: focus order, live regions, contrast decisions
6. Screenshot-agree the checklist; revisit at review together

## Common Pitfalls

- Hover states invented by developers at review time
- Redlines covering happy paths only
