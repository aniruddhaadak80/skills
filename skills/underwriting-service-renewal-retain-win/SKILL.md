# Run renewals that retain good risks

> Early outreach, transparent change explanation, and save motions for wavering accounts.

**Track:** ☂️ Insurance Operations · **Domain:** Underwriting & Service · **Level:** foundation · **~25 min**

**Who this is for:** Claims Adjusters, Underwriters, Insurance Ops, Brokers

## When to Use This Skill

Early outreach, transparent change explanation, and save motions for wavering accounts.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Start renewal review 60+ days out; no last-minute surprise premiums
2. Explain premium changes by driver (losses? market? exposure growth?)
3. Flag accounts with shopping signals for proactive save conversations
4. Prepare alternatives within appetite BEFORE the call, not after objections
5. Document competitive losses with reasons feeding product fixes
6. Measure retention by segment; investigate anomalies both directions

## Common Pitfalls

- Renewal notices as the first touch
- Matching any competitor quote without re-underwriting
