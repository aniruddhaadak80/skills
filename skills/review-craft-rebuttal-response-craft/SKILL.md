# Write rebuttals that flip reviewer votes

> Point-by-point discipline, new-evidence prioritization, and tone that concedes gracefully.

**Track:** 🔬 Scientific Research · **Domain:** Peer Review Craft · **Level:** advanced · **~40 min**

**Who this is for:** Researchers, PhD Students, Postdocs, Research Software Engineers

## When to Use This Skill

Point-by-point discipline, new-evidence prioritization, and tone that concedes gracefully.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Open with summary of changes made, not grievances about scores
2. Address EVERY point; skipping one reads as conceding it
3. Prioritize new experiments/data over rhetorical argument
4. Concede valid criticisms explicitly — credibility compounds
5. Quote reviewer concerns verbatim above each response
6. Enforce page limits ruthlessly: clarity beats completeness

## Common Pitfalls

- Defensive tone converting neutral reviewers to enemies
- Promising future work instead of showing current evidence
