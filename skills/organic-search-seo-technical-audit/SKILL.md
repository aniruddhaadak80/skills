# Audit technical SEO before writing more content

> Crawlability, indexation, Core Web Vitals, and structured data checked in priority order.

**Track:** 📣 Marketing & Growth · **Domain:** Organic Search · **Level:** intermediate · **~40 min**

**Who this is for:** Growth Marketers, Content Strategists, Lifecycle Marketers, Founders

## When to Use This Skill

Crawlability, indexation, Core Web Vitals, and structured data checked in priority order.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Verify indexability: robots.txt, meta noindex leftovers, canonical correctness
2. Fix redirect chains and orphan pages via full crawl analysis
3. Confirm sitemap accuracy against indexed reality in Search Console
4. Pass CWV thresholds on templates receiving organic traffic
5. Implement structured data where rich results genuinely apply
6. Prioritize fixes by traffic-weighted impact, not audit-tool severity defaults

## Common Pitfalls

- Staging noindex accidentally shipped to production
- Content produced onto templates Google cannot render
