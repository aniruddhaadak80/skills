# Read validation signals honestly

> Distinguish politeness from pull using behavior-based criteria.

**Track:** 🚀 Startup & Founders · **Domain:** Validation & MVP · **Level:** intermediate · **~25 min**

**Who this is for:** Founders, Indie Hackers, Early Employees, Solopreneurs

## When to Use This Skill

Distinguish politeness from pull using behavior-based criteria.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Count actions, not compliments: pre-orders, waitlist signups, LOIs
2. Weight paid experiments over free interest every time
3. Track unsolicited follow-ups; pull shows up unprompted
4. Interview churned/declined prospects more than fans
5. Set kill criteria upfront to fight sunk-cost bias
6. Review signal log weekly; patterns beat anecdotes

## Common Pitfalls

- Mom-test failures: friends saying it's nice
- Interpreting survey enthusiasm as demand
